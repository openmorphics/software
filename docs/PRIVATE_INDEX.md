# EventFlow Private Package Index

Pro and Enterprise features are distributed via a private package index.

## Installation

To install licensed packages, you must provide the private index URL:

```bash
pip install eventflow-conformance --extra-index-url https://pypi.eventflow.dev/TOKEN/
```

## Available Pro Packages

- `eventflow-backends-pro`: Certified hardware adapters.
- `eventflow-conformance`: Audit-grade verification and evidence export.
- `eventflow-license`: Internal license validation dependency.

## Authentication

Access requires a valid Token. Pro customers can find their token in the [EventFlow Dashboard](https://eventflow.dev/dashboard).
