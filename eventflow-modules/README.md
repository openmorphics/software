# EventFlow Modules (Community Edition)

This package contains reference domain-specific modules and templates for the EventFlow SDK.

## Included Modules

### Vision (Community)
- **Corner Tracking**: Fast Harris corner detection for event streams.
- **Object Tracking**: Basic centroid-based object tracking.

### Audio (Community)
- **KWS (Keyword Spotting)**: Basic wakeword detection reference.

### Bio-Signals (Community)
- **ECG**: Basic R-peak detection for electrocardiogram signals.
