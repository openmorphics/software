# EventFlow Conformance

This package provides audit-grade conformance verification and evidence export for the EventFlow SDK.

## Features

- **Certification Profiles**: Verify graphs against industry standards (Automotive, Medical).
- **Evidence Export**: Generate signed JSON reports for regulatory compliance.
- **Enhanced Validation**: Deeper checks for determinism, latency, and resource constraints.

## Licensing

This is a **Pro** package and requires a valid EventFlow Pro or Enterprise license.
